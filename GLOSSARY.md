## Cross-cluster argument spines (where the books fight)

These are the most valuable threads in the program — follow them to see how frameworks
contradict, refine, and build on each other. Each spine is a path through the canon.

1. **What is a moat?** Porter (forces) → Christensen (disruption) → Grove (inflection) → Helmer (7 powers) → Thiel (monopoly)
2. **How to decide under uncertainty:** Kahneman (biases) → Munger (inversion) → Tetlock (calibrate) → Mauboussin (skill vs luck) → Bezos (70% + reversibility)
3. **How organizations actually decide:** Kahneman (System 1/2) ↔ Klein (trust intuition) → Kahneman-Noise (reduce scatter) → March (garbage can) → Allison (rational/process/politics)
4. **Persuasion — two schools:** Fisher/Ury (rational, interests-based) ↔ Voss (emotional, empathy-based); Cialdini (the levers) → Carnegie (sincerity) ↔ Greene/Pfeffer (raw power)
5. **Changing people and orgs:** Schein (diagnosis) → Kotter (top-down 8 steps) ↔ Heath/Switch (bottom-up Rider/Elephant/Path) → Horowitz (culture = action) → Clear (habit systems)
6. **Find the one thing:** Rumelt (kernel) → Rumelt (crux) → Goldratt (constraint) → Meadows (leverage point) — Martin: refuse the *false* tradeoff
7. **Execution chain:** Rumelt → Bungay (intent) → Marquet (authority) → Larson (load) → Bossidy/Charan → 4DX (protect from whirlwind)
8. **Surviving the tails:** Taleb-Black Swan → Taleb-Antifragile → Klarman (margin of safety) → Ries (small capped bets)
9. **Why moats exist (rigorous):** Mankiw (markets) → Akerlof (asymmetry/signaling) → Helmer (switching/network) → Shapiro/Varian (lock-in) → Parker/Cusumano/Hagiu (platforms)
10. **The personal OS:** Covey (Q2) → Newport (deep work) → Clear (habit systems)
